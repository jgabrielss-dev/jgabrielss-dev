## Projetos em destaque

### [Agrosantos — Catálogo estático e automação](https://github.com/jgabrielss-dev/AGROSANTOS)
Protótipo de catálogo digital desenvolvido com HTML, CSS e JavaScript. Inclui scripts Python para processar planilhas Excel e gerar JSON, buscar imagens ausentes e um script Bash para encadear as etapas, permitir revisão das imagens e preparar o deploy.

### [Agrosantos Data Pipeline](https://github.com/jgabrielss-dev/agrosantos-data-pipeline)
Evolução do fluxo de processamento de produtos, com interface de gerenciamento remoto. Projeto explora Python, Pandas, Streamlit, tratamento de dados, coleta de imagens e integração com armazenamento e banco de dados em nuvem.

### [Agrosantos Catalog Web](https://github.com/jgabrielss-dev/agrosantos-catalog-web)
Versão mais completa do catálogo, com recursos de gerenciamento remoto e administração de produtos. Projeto de portfólio voltado ao desenvolvimento web e integração com serviços de dados.

### [RegexEngineForBills](https://github.com/jgabrielss-dev/regexengineforbills)
Aplicação em Python que extrai código de barras, vencimento e valor de boletos em PDFs com camada de texto. Utiliza expressões regulares e evita duplicidade de registros. PDFs digitalizados como imagem não fazem parte do escopo atual.

### [Synthesis](https://github.com/jgabrielss-dev/synthesis)
Landing page criada durante a exploração de uma ideia de negócio.
